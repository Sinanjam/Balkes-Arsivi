# Balkes Arşivi 2.0 Final

Bu sürüm, Balkes Arşivi uygulamasının halka açılacak 2.0 final sürümüdür.

## 2.0 ile gelenler

- Kayıp Sayfalar ve Balkes Arşivi ayrımı kaldırıldı; tüm içerikler tek ve düz Balkes Arşivi bölümü altında toplandı.
- İçerik sayfaları PDF/dergi tarzı arşiv okuyucu yapısına çevrildi.
- Görseller artık sayfanın üstüne yığılmıyor; metinlerin doğal akışı içinde ilgili bölümlere yerleşiyor.
- Metinler tam metin mantığıyla gösteriliyor.
- Fotoğraf, tablo, maç skoru ve metin blokları daha okunabilir arşiv sayfası düzenine alındı.
- Ziyaretçi defteri kaldırıldı.
- Başlıklardan ve içeriklerden Kayıp Sayfalar ibaresi temizlendi.
- Arama ekranındaki filtre kutusu kaldırıldı.
- Arşiv içindeki Güncelle kutucuğu kaldırıldı.
- Güncelleme kontrolü artık splash screen üzerinden GitHub latest release kontrolüyle yapılıyor.
- İnternet varsa uygulama açılışında GitHub latest release taranır; yeni sürüm varsa latest release sayfasına yönlendirir.
- Ana ekrana Favoriler kutucuğu eklendi.
- Favoriler bölümü Favori Fotoğraflar ve Favori Yazılar olarak ikiye ayrıldı.
- Eksik fotoğraflar için sembolik/temsili görseller eklendi.
- Temsili görsellerin altında Temsilidir notu gösteriliyor.
- Kapak fotoğrafı olmayan içerikler boş bırakılmak yerine arşiv temalı görsellerle desteklendi.
- Puan tabloları mobil uyumlu tablo/kart görünümüne taşındı.
- Temsili puan tabloları dolduruldu ve altına Temsilidir notu eklendi.
- Maç skorları için özel skor kartı/tablo görünümü oluşturuldu.
- Maç sonuçlarında tarih, takım, skor ve rakip bilgileri daha düzenli gösteriliyor.
- Ham Markdown başlıklarının ekranda görünmesi engellendi.
- Boş tablo başlıkları ve gereksiz dev boşluklar temizlendi.
- Üst ve alt sistem çubuğu boşlukları iyileştirildi.
- Yazı boyutu ve satır aralığı okunabilirlik için artırıldı.
- Fotoğraf kaydetme, paylaşma ve favoriye alma akışı korundu.
- Metin favorileme akışı korundu ve ana ekrandaki Favoriler bölümüne bağlandı.
- Hakkında bölümü sadeleştirildi.
- Sabit imza anahtarı korunarak güncellemelerde uygulamayı silmeden yükleme desteği sürdürüldü.
- NixOS üzerinde yerel release APK üretimi için build dosyaları güncellendi.
